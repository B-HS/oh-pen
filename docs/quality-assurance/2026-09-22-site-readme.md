# 웹사이트·README 마무리 검증

## 대상 파일

README, `docs/pen/installer.md`, `scripts/site/{docs,pages,shell,theme}.ts`, `scripts/site/docs.test.ts`, `scripts/build-site.ts`.

## 리포트

홈페이지에서 v0.2의 작업 계약·실행 한도·취소와 재개·결과 확인을 바로 찾아볼 수 있도록 정리했습니다. README에는 설치 후 시작 방법, 실제 uninstall 동작, 백업 대상, 재개와 실행 한도, 외부 모델 검증 범위를 명시했습니다. 설치 문서의 자산 목록·모델 목록·다운로드 순서를 현재 코드와 맞췄습니다.

## 재현과 수정

- 배포된 설계 문서의 실행 안내를 클릭하면 `/docs/runtime.md`로 이동해 404가 발생했습니다. 문서 발행 시 등록된 Markdown 상대 링크를 실제 HTML 경로로 변환합니다.
- 중첩 경로의 404에서 홈·문서·스타일 경로가 중첩되어 복구 링크가 깨졌습니다. 404의 기준 경로를 GitHub Pages 사이트 루트로 지정했습니다.
- 모바일 실행 안내의 화면 폭은 390px인데 문서 폭은 451px였습니다. 긴 인라인 코드를 줄바꿈하고 코드 블록의 내부 스크롤은 유지해 390px로 맞췄습니다.
- 빌드가 CSS 파일까지 페이지로 집계했습니다. HTML만 집계하도록 고쳤으며 실제 산출물은 HTML 11개와 CSS 1개입니다. 이전 기록의 “12 pages”는 CSS를 포함한 당시 로그 값입니다.
