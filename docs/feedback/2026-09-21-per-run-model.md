# 작업별 모델 지정 시 agent 파일 변경

## 지적

사용자가 workflow의 모델을 지정하면 `pen`이 설치된 `.md` 파일의 `model:`을 바꿔 실행하려 한다. 사용자는 이 파일을 수정하지 않고 서브에이전트 실행 명령의 모델 플래그로 해당 작업에만 적용하도록 요청했다.

## 잘못된 판단

native `subagent` 도구에 호출별 model 인자가 없다는 제약을 작업별 모델 선택 전체의 제약으로 확장했다. 그 결과 지속 설정인 agent `.md`를 일시적 작업 선택에 사용하도록 지시했다.

## 수정과 적용 시점

- 기본 설치 모델을 선택한 작업은 native `subagent`로 실행한다.
- 현재 pen 모델 상속이나 역할별 사용자 지정 모델을 선택한 작업은 `opencode run --agent <역할> --model <모델> <완전한 작업 계약>`으로 별도 실행한다.
- 별도 CLI 세션은 native child가 아니므로 문맥·완료 알림을 자동 상속하지 않는다. 메인이 결과를 직접 회수한다.
- 작업별 선택은 agent `.md`나 root config를 변경하지 않는다. 모델이 없거나 CLI 실행이 불가하면 설정 변경으로 우회하지 않는다.

## 승격 후보

모든 제품에 일괄 적용할 보편 규칙은 아니다. OpenCode V2의 현재 호출 경계에서만 적용하므로 `docs/memory` 승격 후보가 아니다.
