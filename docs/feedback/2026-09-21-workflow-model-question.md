# workflow·모델 시작 질문 누락

## 지적

사용자는 조사 에이전트가 설치 때 정한 모델로 바로 실행되고 workflow 사용 여부와 모델을 묻지 않는 동작을 지적했다. 기본 모델은 현재 GPT 역할 배정을 유지하되, workflow 사용 여부를 물을 때 모델 선택도 함께 물어야 한다고 확정했다.

## 잘못된 판단

“최대한 개입 없이 진행”을 시작 선택까지 제거하라는 의미로 확대 해석해 `pen`이 workflow를 자동 판단하고 설치 모델을 재질문 없이 사용하도록 바꿨다. 이는 새 도구 작업마다 workflow 선택을 받는 `ai-process.md` 계약과 사용자가 원한 역할별 모델 선택권을 약화했다.

## 수정 원칙

1. 새 도구 사용 작업마다 workflow 사용 여부와 subagent 모델 방식을 한 번에 묻는다.
2. 기본 모델 선택은 설치된 GPT 역할 배정을 그대로 사용한다.
3. 사용자는 primary 상속 또는 OpenCode에 연결된 역할별 모델을 직접 지정할 수 있다.
4. 개입 최소화는 시작 선택 이후의 조사·구현·검증·일반 Git 통합에 적용한다.

## 적용 시점

`pen`의 새 작업 시작, 새 세션, resume, clear, compact, handoff, `PROCESS.md` 기반 재개에 적용한다.

## 승격 후보

`docs/memory` 승격 후보가 아니다. 이미 `ai-process.md`에 있는 보편 규칙을 제품 agent 자산과 문서가 위반한 회귀이므로 해당 계약을 직접 복구한다.
